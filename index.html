        Data coverage & limitations

        One sighting per address per clock minute, across selected files. Locations use fixed 200 m anchors. All thresholds must hold within one rolling 12-hour window.

        Re-logging limits, rotating addresses and export exclusions can hide evidence. Nothing is automatically trusted at the start. Empty results cannot establish that nothing traveled with you.

        About trusted devices

        Use Trusted to manage your saved list. Only a full SHA-256 digest of each normalized address and radio type is saved on this browser and local address. Hashes are pseudonymous, not encryption. Names, locations and sightings are never saved.

        Trust suppresses movement candidacy only, not notable detections. Clearing captures keeps this list. Remove trust to restore eligibility immediately.

        Saved trust changes synchronize between Atlas tabs on this local address. If a safe save is unavailable, the change is labeled Tab-only and stays here until this page closes. Use Save change to explicitly retry one change; other actions never save it automatically.
